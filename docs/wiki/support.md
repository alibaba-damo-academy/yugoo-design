# 问题反馈与参与

欢迎反馈语构设计系统（Yugoo Design）的使用问题、缺陷、功能建议，以及设计套件（Kit）和设计技能包（Bundle）的方法与交互体验。贡献入口见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

## 反馈一个问题

可以通过联系邮箱 [yangjianfeng.yjf@alibaba-inc.com](mailto:yangjianfeng.yjf@alibaba-inc.com) 反馈问题或建议。公开仓库的 Issues 入口和问题模板仍待配置。

建议包含：

1. 使用的插件版本、宿主名称与版本、操作系统。
2. 最小复现步骤、预期行为和实际行为。
3. 失败发生于安装、登记、连接、生成、Panel、保存或重开哪一步。
4. 去除隐私信息后的错误、截图和合成示例。

可以复制以下模板，保留与问题有关的项：

```text
问题：
插件版本（桌面套件和 npm 包分别填写；测试包附构建编号）：
宿主名称与版本：
操作系统与 CPU 架构：
失败阶段（安装/登记/连接/生成/面板/保存/续作/重开）：
最小合成输入与复现步骤：
预期结果：
实际结果与非敏感错误：
是否可重复、是否涉及其他并发操作：
已尝试的处理：
```

性能问题请补充任务规模、开始和完成时间，并尽量说明耗时发生在模型生成、消息回传、页面刷新还是保存。定位步骤见[故障排查](troubleshooting.md)。如果想使用尚未支持的环境，也欢迎说明需求。

不要提交凭据、完整认证 URL、真实私密项目或会话日志。安全问题按[安全报告说明](../../SECURITY.md)走私密渠道。

## 提出建议或贡献

描述使用场景、遇到的阻碍以及希望达到的结果。代码、专业方法、文档、翻译与示例贡献按[贡献指南](../../CONTRIBUTING.md)准备范围和验证信息。

## 反馈套件的方法与交互体验

即使没有报错，也欢迎指出让你难以理解、判断或表达的地方。例如，智能体（Agent）过早推进下一步，设计面板（Design Panel）只给出文字结论却看不到具体规则，或修改一处设计后不知道其他部分是否受影响。这类反馈有助于检查领域主提示词（Mindset）的引导与 Bundle 的结果面板是否配合顺畅。

通过上面的联系渠道，描述你实际经历的一小段过程即可，不需要懂提示词或代码。可以使用以下提纲，保留相关项：

```text
正在设计什么、想作出什么决定：
使用的套件与面板（能提供时附版本）：
Agent 提出了什么建议或问题，面板展示了什么：
哪里看不懂、缺少哪些信息，或想修改却无法表达：
你给出了什么反馈，之后发生了什么：
你希望下一步怎样帮助你：
```

例如：“我已经在排班约束里确认了晚班最低人数，随后修改了员工可用时间。我希望看到这会影响哪些约束，Agent 却直接建议输出模型。”这样的过程比“建议更智能一点”更便于定位问题。附图或示例仍需去除真实业务数据与私人信息。
