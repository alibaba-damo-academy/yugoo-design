# 调研可信信息源参考（按调研主题分类）

本表服务「为搭应用做调研」：用户要做某产品 → 调研竞品/市场/用户/技术/合规/数据/设计，给设计提供依据。
类目按这些常见调研意图组织，**是优先级参考，不是封锁名单**。同类目越靠前越权威；官方/政府/国际组织任何主题都最高优先。
URL 必须真实出现在检索结果里（禁编造）。维护：改本文件即可，无需改代码。

## 用法 & 开放策略
- 命中类目权威源 → 直接采信、高优先；命中权威就别拿低质源凑数。
- **没命中清单也别丢**：按质量自判——原始/一手、机构权威、作者署名+日期、与多源一致 → 可用；匿名/带货/SEO 农场/无来源/与权威冲突 → 降级或弃用。
- **类目里没有你这主题**（如农业/法律/医疗/游戏/硬件…）：自助找该领域「同位源」——①官方机构/标准/监管 ②专业数据库/期刊 ③头部行研机构 ④头部社区/论坛；再套上面质量判断。
- 社区/论坛/问答=高价值线索源，但是观点非定论：用它发现方向与一手链接，结论回到权威源交叉验证。
