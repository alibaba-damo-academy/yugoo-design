# Cedar Requests — current product, 2026-09-08

Cedar Requests is a small club's expense-request tool. Members submit expenses
and reviewers decide them. This is the whole product, not a reusable workflow
engine. People join by invitation and sign in; requests are stored in a server
database. The source materials do not establish a business model or pricing.

A request retains its title, amount in yuan, applicant and current status:
draft, submitted, approved or rejected. The applicant identifies the member who
created it; two people with the same display name are still different members.
An amount is always required. A receipt is required only for amounts above
200 yuan. There is no category field in the current product.

The request list opens a request detail. Members create drafts, edit their own
drafts and submit them. Reviewers inspect submitted requests and approve or
reject requests from other people. An applicant can read their own request's
result. There are no charts, exports or payment execution surfaces.

Member access is granted when joining by invitation. Reviewer access is granted
by the club administrator. The administrator's other application permissions
are not described here. The materials do not establish multiple simultaneous
roles. Whether an approved request can later be withdrawn is undocumented.
